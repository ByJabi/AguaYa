# AguaYa

Plataforma de intermediación y gestión de servicios
de distribución de agua potable en Aguachica, Cesar.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PostgreSQL
- Git y GitHub

## Arquitectura

El proyecto se divide en tres componentes:

- frontend: interfaz de usuario.
- backend: API y lógica del negocio.
- database: estructura y persistencia de datos.

## Estado del proyecto

Etapa inicial de estructuración del MVP.
